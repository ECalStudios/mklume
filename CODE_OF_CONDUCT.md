# Code of Conduct

## Our pledge

MkLume is an open-source project created by Enrique Cal — ECal Studios.

We want the MkLume community to be welcoming, respectful, and helpful for everyone, including beginners, experienced developers, documentation writers, and open-source contributors.

Everyone participating in this project is expected to treat others with respect.

## Expected behavior

Examples of positive behavior include:

- Being kind and patient
- Giving constructive feedback
- Respecting different experience levels
- Asking questions in good faith
- Helping keep discussions focused and useful
- Reporting bugs clearly and respectfully

## Unacceptable behavior

Examples of unacceptable behavior include:

- Harassment, insults, or personal attacks
- Discriminatory language or behavior
- Trolling or intentionally disruptive comments
- Sharing private information without permission
- Posting spam or unrelated promotion
- Demanding unpaid work or immediate support
- Abusive behavior toward maintainers or contributors

## Project spaces

This Code of Conduct applies to project spaces such as:

- GitHub Issues
- Pull requests
- Repository discussions, if enabled in the future
- Any official MkLume community or support spaces

## Technical support

GitHub Issues are used for:

- Bug reports
- Feature requests
- Questions about MkLume

Ko-fi is only for optional donations and supporting development. It is not the technical support channel.

## Enforcement

The project maintainer may remove comments, close issues, block users, or restrict participation when behavior is harmful, abusive, spammy, or clearly outside the purpose of the project.

The goal is not to be strict for no reason. The goal is to keep MkLume useful, respectful, and safe for everyone.

## Attribution

This Code of Conduct is inspired by common open-source community guidelines and adapted specifically for MkLume.
