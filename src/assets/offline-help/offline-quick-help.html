MkLume Quick Help

Offline reference — no internet required

For complete documentation, visit www.ecalstudios.com/mklume

What is MkLume?

MkLume is a visual desktop editor for MkDocs Material documentation. It runs locally on your computer and edits your project files directly.

Creating a Project

New Project

Click New Project on the welcome screen, or use Ctrl+N. Enter a site name, choose a folder, and MkLume will create a starter mkdocs.yml and docs/index.md for you.

Open Existing Project

Click Open Existing Project or use Ctrl+O. Select any folder that contains a mkdocs.yml file. Recent projects appear on the welcome screen for quick access.

Editor Modes

Markdown Mode (Ctrl+1)

Raw Markdown editing with a toolbar and keyboard shortcuts. Use the Insert menu for admonitions, tables, tabs, grid cards, and more.

Visual Mode (Ctrl+2)

Block-based visual editing. Add and edit headings, paragraphs, images, code blocks, admonitions, lists, tables, and more without writing Markdown.

Preview Mode (Ctrl+3)

Rendered preview of the current page. Toggle between Page Preview (content only) and Site Preview (full Material site layout with header, sidebar, and TOC).

Split View (Ctrl+4)

Side-by-side editing and preview. Choose any combination: Markdown or Visual on the left, Page or Site Preview on the right.

Images & Assets

Drag and drop images onto the editor. MkLume copies them to docs/assets/ and inserts the Markdown image syntax automatically. Supported formats: PNG, JPG, GIF, SVG, WebP.

Smart Internal Links

Type [[ or [Text]( in Markdown mode to trigger autocomplete. Select a page and MkLume inserts a link with the correct relative path. You can also use Insert > Internal Link to browse all pages.

Site Settings

Open View > Site Settings to edit your mkdocs.yml visually. Configure site identity, theme, Material features, palette colors, plugins, extensions, and extras without editing YAML directly.

Build & Export

Open the Build Panel from the toolbar or Tools > Build Site.

  • Build to Folder — generates site/ directory
  • Build to ZIP — creates a distributable archive
  • Build Both — folder and ZIP

Upload the output to any static hosting provider. MkLume never needs your hosting credentials.

MkLume includes a bundled MkDocs runtime. No separate Python or MkDocs installation is needed for building.

Git Sync

Open Tools > Git Sync to commit and push your changes. MkLume detects your Git repository, shows changed files, and lets you write a commit message. Authentication uses your local Git configuration (SSH keys, credential managers).

GitHub Pages Deploy Assistant

Open Tools > GitHub Pages Deploy Assistant. MkLume generates a GitHub Actions workflow file — no tokens, no passwords. After generating the workflow, commit and push your changes, then enable GitHub Pages in your repository settings with "GitHub Actions" as the source.

Backups & Recovery

  • Autosave — saves automatically after a configurable delay.
  • Backup before save — creates a timestamped copy in .mklume/backups/.
  • Recovery drafts — periodic snapshots in .mklume/recovery/, restored if unsaved work is detected.

Quick Troubleshooting

MkDocs runtime error

MkLume includes a bundled MkDocs runtime. If it fails to start, try reinstalling MkLume. If the problem persists, report it at GitHub Issues.

Build failed

Check the build output log for errors. Common causes: missing extensions, invalid YAML in mkdocs.yml, or broken image paths.

Images not showing in preview

Make sure the image file exists in docs/assets/ and the Markdown path is correct. External URLs require internet.

Git push failed

Check your Git authentication (SSH keys or credential manager). Make sure you have push access to the remote repository.

Privacy

MkLume is local-first. It edits files on your computer, does not require cloud login, does not ask for tokens or credentials, and does not include built-in telemetry. Backups and recovery data are stored locally in your project directory.
