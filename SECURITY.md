# Security Policy

Thank you for helping keep MkLume safe.

MkLume is a local-first desktop app for creating, editing, previewing, and managing MkDocs Material documentation.

## Reporting a security issue

Please do not report security vulnerabilities in public GitHub Issues.

If you believe you found a security issue, please contact ECal Studios privately first.

Until a dedicated security contact is published, please use the contact options available on the official ECal Studios website:

https://www.ecalstudios.com

When reporting a security issue, please include:

- A clear description of the problem
- Steps to reproduce it
- The affected MkLume version, if known
- Your operating system
- Any relevant logs or screenshots
- Whether the issue could expose, modify, or delete user files

Please do not include passwords, tokens, private keys, or sensitive personal data in reports.

## Scope

Security reports may include issues related to:

- Unsafe file handling
- Unexpected access to files outside the selected workspace
- Unsafe command execution
- Path traversal problems
- Local data exposure
- Dependency vulnerabilities that affect MkLume directly

## Out of scope

The following are usually not considered MkLume security issues:

- General MkDocs or Material for MkDocs configuration questions
- Problems caused by third-party plugins outside MkLume
- Issues requiring full access to the user's own computer
- Social engineering
- Denial-of-service reports without a realistic security impact

## Supported versions

MkLume is currently preparing its first public release.

Security support applies to the latest public version once releases are available.

## Responsible disclosure

Please give reasonable time for the issue to be reviewed and fixed before sharing details publicly.

Thank you for helping improve MkLume.
