# MkLume v1.0.0 — Windows Installer Test Checklist

Installer: `MkLume_1.0.0_x64-setup.exe` (~39 MB)
Build type: NSIS (64-bit)
Includes: Bundled MkDocs runtime sidecar

## Pre-install (Icon Cache)

- [ ] Uninstall previous MkLume if installed
- [ ] Delete old desktop shortcut manually if it remains
- [ ] Run `ie4uinit.exe -show` in Command Prompt
- [ ] Restart Windows Explorer (Task Manager > Explorer > Restart)
- [ ] If old icon persists, restart Windows

## Installation

- [ ] Run `MkLume_1.0.0_x64-setup.exe`
- [ ] Windows SmartScreen warning appears (expected for unsigned app)
- [ ] Click "More info" then "Run anyway"
- [ ] Installation completes without errors
- [ ] App appears in Start Menu
