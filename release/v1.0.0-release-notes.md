# MkLume v1.0.0

**A visual desktop editor for MkDocs Material documentation.**

MkLume is a local-first desktop workspace for creating, editing, previewing, and managing MkDocs Material documentation. It runs entirely on your machine — no accounts, no cloud, no subscriptions.

## Highlights

- **Markdown Mode** — Raw Markdown editing with toolbar, keyboard shortcuts, and Insert menu for admonitions, tabs, tables, grid cards, and more.
- **Visual Editor** — Block-based visual editing with 18+ block types. Edit headings, paragraphs, images, code blocks, admonitions, and lists without writing Markdown.
- **Preview & Site Preview** — Rendered page preview and approximate MkDocs Material site layout with header, sidebar, TOC, and footer.
- **Flexible Split View** — Side-by-side editing and preview with four combinations.
- **Drag-and-Drop Images** — Drop images onto the editor. MkLume copies them to `docs/assets/` and inserts the Markdown.
- **Smart Internal Links** — Type `[[` or `[Text](` to trigger page autocomplete with correct relative paths.
- **Site Settings Editor** — Edit `mkdocs.yml` visually: site identity, theme, Material features, palette, plugins, extensions, and extras.
- **Navigation Editor** — Drag-and-drop reordering, add/remove pages, create groups, clean up missing entries.
- **Project Health** — Scan for broken links, missing images, nav issues, extension problems, and content warnings.
- **Build & Export** — Build your site to a folder, ZIP, or both. Upload to any static hosting provider.
- **Git Sync** — Commit and push from within MkLume. No force push, no destructive operations.
- **GitHub Pages Deploy Assistant** — Generate a GitHub Actions workflow for automated deployment. No tokens, no passwords.
- **Autosave, Backups & Recovery** — Configurable autosave, timestamped backups, and crash-recovery drafts.
- **Offline Quick Help** — Built-in quick reference that works without internet.
- **Light & Dark Mode** — Full theme support with system preference detection.
- **Command Palette** — Quick access to every command with `Ctrl+K`.

## Security & Privacy

MkLume is local-first. It edits files on your computer, does not require cloud login, does not ask for tokens or credentials, and does not include built-in telemetry. Backups and recovery data are stored locally in your project directory.

## Known Limitations

- Windows only for the initial release. macOS and Linux support is planned.
- MkLume is not code-signed yet. Windows SmartScreen may show a warning for unsigned applications.
- The in-app preview is an approximation — for exact output, use `mkdocs serve`.
- Some complex nested Markdown structures appear as Raw Markdown blocks in Visual Mode.
- Git Sync requires [Git](https://git-scm.com/) to be installed on your system.
- Build/Export/Serve use a bundled MkDocs runtime — no separate Python or MkDocs installation required.
