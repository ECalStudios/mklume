# MkLume v1.0.1

This is a small patch release focused on Visual mode rendering and editing polish for MkDocs Material documentation.

## Highlights

- Visual mode now renders MkDocs Material card grids more cleanly.
- Card images render as thumbnails when image paths can be resolved.
- Missing card images use a cleaner fallback.
- Inline links and images inside cards render more cleanly.
- Docs/Fab link rows have better spacing.
- Preview mode card rendering is improved.
- Icon shortcodes render more consistently in Visual and Preview modes.
- Icon insertion is available through the Insert menu and slash command in Visual mode.
- Visual block controls are easier to see and use in dark mode.
- Markdown remains the source of truth — no source format changes.

## Download

The v1.0.1 Windows installer will be attached to the GitHub Release after manual testing.

**Windows installer includes bundled MkDocs runtime.** Normal Windows users do not need to install Python, MkDocs, Material for MkDocs, Node, Rust, or any developer tools.

## Known Limitations

- Windows installer is unsigned. Windows SmartScreen may show a warning on first run.
- macOS and Linux packages are not included yet. Community contributors welcome.
- Git Sync requires Git installed and configured by the user.
- Advanced source builds require developer tooling (Node.js, Rust, Cargo).
