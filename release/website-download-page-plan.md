# Website Download Page Plan

https://www.ecalstudios.com/mklume/ (download section or separate /download/ page)

1. **Download Button** — Points to GitHub Releases after Milestone 42
   - URL: https://github.com/ECalStudios/mklume/releases
   - Label: "Download for Windows"
   - Show version and file size

2. **Source Code Button**
   - URL: https://github.com/ECalStudios/mklume
   - Label: "View Source on GitHub"

3. **Issues/Support Button**
   - URL: https://github.com/ECalStudios/mklume/issues
   - Label: "Report Issue / Get Support"

4. **Donation Button**
   - URL: https://ko-fi.com/ecalstudios
   - Label: "Support Development"
   - Note: Donation only, not required

5. **Documentation Link**
   - URL: https://www.ecalstudios.com/mklume/
   - Label: "Read the Documentation"

## Content Notes

- Windows installer listed first (only available platform for v1.0.0)
- macOS/Linux listed as "planned / community contributions welcome"
- Unsigned Windows app warning with SmartScreen instructions
- "No developer tools required" messaging for normal users
- SHA-256 checksum verification instructions
- System requirements: Windows 10+, WebView2, optional Git
