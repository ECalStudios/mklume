# Release Planning

This folder contains release preparation notes for MkLume.

These files are for maintainer reference only. They are not part of the application or documentation site.

## Contents

- `v1.0.0-release-notes.md` — Draft release notes for GitHub Releases
- `v1.0.0-checklist.md` — Pre-release, build, release, and post-release checklist
- `v1.0.0-windows-test-checklist.md` — Windows installer test checklist
- `checksums-notes.md` — How to generate and publish checksums for installer files
- `website-download-page-plan.md` — Plan for the website download section
- `github-upload-commands.md` — Commands to upload source code to GitHub
- `artifacts/` — Local build output (not committed to source repo)
