## Resolved risks

### MkDocs dependency — RESOLVED

The Windows installer now includes a bundled MkDocs runtime sidecar (`mkdocs-runner`). Normal users do not need to install Python or MkDocs manually. Build, Export, and Serve all use the bundled runtime.

**Remaining external dependency:** Git Sync requires Git to be installed by the user. This is acceptable because Git is widely installed and Git Sync is an optional feature.
