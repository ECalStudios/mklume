## Third-party dependencies

MkLume is built on top of many excellent open-source projects. Each dependency retains its own license. Key technologies include:

- **Tauri** — desktop application framework (MIT / Apache 2.0)
- **React** — user interface library (MIT)
- **TypeScript** — typed JavaScript (Apache 2.0)
- **Rust** — systems programming language (MIT / Apache 2.0)
- **MkDocs** — static site generator for documentation (BSD)
- **Material for MkDocs** — MkDocs theme (MIT)

For the full list of dependencies and their licenses, see the project's `package.json` and `Cargo.toml` files.
