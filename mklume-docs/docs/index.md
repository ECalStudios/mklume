# MkLume

**A visual desktop editor for MkDocs Material documentation.**

MkLume is a local-first desktop workspace for creating, editing, previewing, and managing MkDocs Material documentation. It runs entirely on your machine — no accounts, no cloud, no subscriptions. Just open a folder and start writing.

Whether you're documenting a software project, building a knowledge base, or writing a manual, MkLume gives you a clean, focused workspace with the tools you need and nothing you don't.

## Features

<div class="grid cards" markdown>

- :material-format-text: **Visual Editing**

    ---

    Edit your pages in a rich visual mode with formatting controls, without needing to write raw Markdown. Great for beginners or anyone who prefers a visual workflow.

- :material-language-markdown: **Markdown Editing**

    ---

    Full Markdown editor with syntax highlighting for when you want direct control over your content. Switch freely between Visual and Markdown modes.

- :material-eye: **Site Preview**

    ---

    See how your documentation will look before you publish. MkLume renders a live preview of the current page as you write.

- :material-view-split-vertical: **Flexible Split View**

    ---

    Work in editor-only, preview-only, or side-by-side split view. Adjust the layout to match your workflow.

- :material-image-plus: **Drag-and-Drop Images**

    ---

    Drop images directly into the editor. MkLume copies them into your project's docs folder and inserts the Markdown reference automatically.

- :material-link-variant: **Smart Internal Links**

    ---

    Link to other pages in your project without memorizing file paths. MkLume helps you create internal links that stay valid.

- :material-cog: **Site Settings Editor**

    ---

    Configure your site name, description, theme colors, and other `mkdocs.yml` settings through a visual interface — no need to edit YAML by hand.

- :material-puzzle: **Extras & Integrations**

    ---

    Add analytics, custom CSS/JS, and other extras through a guided settings panel.

- :material-heart-pulse: **Project Health**

    ---

    See warnings about broken links, missing images, and other issues across your documentation project.

- :material-hammer-wrench: **Build and Export**

    ---

    Build your MkDocs site from within MkLume and export a ready-to-deploy static site. Requires Python and MkDocs installed locally.

- :material-git: **Git Sync**

    ---

    Commit, push, and pull your documentation project with the built-in Git panel. Requires Git installed on your system.

- :material-rocket-launch: **GitHub Pages Deploy Assistant**

    ---

    Generate a GitHub Actions workflow file to deploy your docs to GitHub Pages. MkLume creates the file — you push it to your repo.

- :material-backup-restore: **Autosave, Backups & Recovery**

    ---

    Your work is autosaved as you type. MkLume keeps rolling backups so you can recover previous versions if something goes wrong.

</div>

## Download

Download the Windows installer from [GitHub Releases](https://github.com/ECalStudios/mklume/releases). macOS and Linux packages are planned for a future release.

No Python, MkDocs, or developer tools required — the installer includes everything you need.
